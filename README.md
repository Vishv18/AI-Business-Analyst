# AI Business Analyst

An AI-powered business analytics system that allows users to ask business questions in natural language and receive data-driven answers, SQL analysis, visualizations, and business insights.

## Project Status

🚧 Project setup and dataset exploration in progress.

## Planned Technologies

- SQL / MySQL
- Python
- Pandas
- Power BI / Data Visualization
- Streamlit
- Large Language Models (LLMs)
- Git & GitHub

## Dataset

This project uses the Olist Brazilian E-Commerce Public Dataset.

The raw dataset is kept locally and is not uploaded to GitHub.

## Planned Workflow

Natural Language Question  
↓  
AI Question Understanding  
↓  
SQL Generation  
↓

↓

↓  
Results & Visualization  
↓  
AI-Generated Business Insight
